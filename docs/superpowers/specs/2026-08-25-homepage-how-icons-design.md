# Homepage “SEC-GO 如何工作”图标设计

## 范围

仅替换首页“SEC-GO 如何工作”区域三张卡片中的占位字符图标。不得修改布局、间距、卡片尺寸、文字、颜色、字体、边框、阴影、响应式行为或其他图标。

## 图标

- `任务理解`：文档、清单与放大镜组成的线性图标，表达任务分析与规划。
- `Agent 协作`：三个互联节点组成的协作网络，表达多智能体协调。
- `证据与报告`：报告文档与盾牌勾选标记组成的线性图标，表达证据验证与结构化报告。

## 实现

在现有 `Icon` 组件中新增三个命名图标，沿用其 `24×24` viewBox、`1.7` 描边、圆角线帽和 `currentColor`。首页仅将三个占位字符替换为对应 `Icon`，不修改任何 CSS。

## 验证

- 组件测试确认三张卡片分别渲染正确的命名 SVG。
- 组件测试确认原占位字符不再出现。
- 运行完整测试、TypeScript 类型检查和生产构建。
